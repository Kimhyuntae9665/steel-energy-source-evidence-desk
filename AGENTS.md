# P12 scope

Own only this independent public UCI energy evidence desk. CPU only until an explicit inference handover. No credentials, weights, host scanning, live equipment access or account/security changes.

Original ZIP/CSV bytes are immutable and pinned by data/admission.json. Source date labels and row order are authoritative: 00:00 remains after 23:45 in each labeled day. Do not infer timezone or physical interval boundaries. Exact decimal energy arithmetic belongs only to deterministic code. Publisher carbon name/unit inconsistency stays unresolved; no bills, savings, production tonnes or fault explanations. Allowlisted source filters only; no generated SQL/Python execution. Every receipt binds source hash, exact filter, contributing row IDs and exclusions. Synthetic tests are separate from actual-source audit evidence.
